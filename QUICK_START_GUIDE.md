## 📊 Input Data Reference

### Soil Data (Get from soil testing kit)
- **Nitrogen (N)**: 0-200 kg/hectare
  - Low: 0-50 (needs fertilizer)
  - Good: 51-120 
  - High: 121+ (rich soil)

- **Phosphorus (P)**: 0-100 kg/hectare
  - Low: 0-15 (needs phosphate)
  - Good: 16-50
  - High: 51+ (excellent)

- **Potassium (K)**: 0-300 kg/hectare
  - Low: 0-60 (needs potash)
  - Good: 61-180
  - High: 181+ (very fertile)

- **pH Level**: 4.0-9.0
  - Acidic: 4.0-6.5 (blueberries, potatoes)
  - Neutral: 6.6-7.3 (most crops)
  - Alkaline: 7.4-9.0 (needs treatment)

### Weather Data (Current conditions)
- **Temperature**: Your current air temperature (°C)
- **Humidity**: Air moisture 0-100% (use weather app)
- **Rainfall**: Recent rain in millimeters

## 🆘 Troubleshooting

### "Can't Connect" Error:
1. Check if server is running (look for terminal window)
2. Try `http://127.0.0.1:5000` instead
3. Restart: Close everything, run `python src/api.py`

### Page Won't Load:
1. Refresh: Press **F5** or **Ctrl+R**
2. Clear cache: **Ctrl+Shift+Delete**
3. Try different browser

### No Results After Analysis:
1. Check all required fields are filled
2. Wait 15 seconds for processing
3. Ensure values are in correct ranges

### Need Help:
1. Click **"Help"** in top navigation
2. Look for **question mark (?)** icons
3. Use **"Take Tutorial"** for refresher
