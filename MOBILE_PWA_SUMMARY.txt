🚀 HOW TO USE
───────────────────────────────────────────────────────────────────────────────

   python src/api.py

2. OPEN IN BROWSER

   Mobile:  http://localhost:5000 (auto-detected)

   - Desktop: Click install prompt in omnibox
   - iOS: Tap Share → Add to Home Screen
   - Android: Tap menu → Install app
